# Exp22 — zk층 STARK화(P10): 추출기 스캔을 해시전용 FRI-STARK로 증명

> 2026-08-27 · Exp21이 명기한 급소 수리: zk "증명" 층이 halo2-KZG(페어링=Shor
> 취약)라 PQ 아님. 이 실험은 그 층을 **해시 전용 투명 증명(FRI-STARK)**으로 옮길
> 수 있음을 실측한다. 대상: 추출기의 계산 심장 = SSM 스캔 재귀 h_{t+1}=a·h_t+b·u_t
> (Exp1/14). KZG 페어링을 제거하고 SHA-256 Merkle만 쓴다(양자 안전 프리미티브).

## 사전 등록 킬 기준 (실행 전 박제)

- **K1 완전성**: 유효 스캔 트레이스 → 전이 제약 몫이 차수 < N → FRI 수락·전체
  검증 True (여러 무작위 유효 트레이스에서).
- **K2 소운드니스(변조 기각)**: 트레이스 한 값 변조 → 몫이 고차 → FRI/일관성
  검증 False. 다수 변조 시행에서 기각률 ≥ 99%.
- **K3 지상진리 정합**: FRI 판정이 직접 차수 검사(몫 계수 N.. 가 0인가)와 유효·
  변조 양쪽에서 일치. (FRI의 미묘한 버그를 잡는 독립 오라클.)

## 정직성 라벨

- **교육급 FRI**다 — 작은 31비트 필드(p=3·2^30+1), 감사받지 않은 자작 구현.
  프로덕션 이식은 risc0/plonky2/winterfell 몫(타당성 실증이 이 실험 목적).
- 대상은 **스캔 재귀**(추출기 심장)이지 24k 전체 망이 아니다 — 후속.
- Fiat-Shamir의 양자 지식-소운드니스는 학계 미완(알려진 양자 공격 없음, 웹 실측).
  이 실험은 "페어링 없는 해시전용 투명 증명이 우리 계산에 성립"을 보인다.
