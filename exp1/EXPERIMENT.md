# Exp1 — 자연어 다단계 논리: 종단 신경망 vs 추출기+기호 검증기

> 지능 불변 보안 연구 (강령: ~/jarvis-ui/agents/작업서/2026-08-26_지능불변보안_연구강령-v1.md)
> 기둥 P6(경량 AI)·시금석(논리 무결성) 소속 · 2026-08-26 설계·실행

## 가설 (지휘자 원안의 교정판)

**H: 같은 수준의 파라미터 예산에서, [경량 추출기 + 기호 검증기] 파이프라인이
[종단 소형 신경망]보다 자연어 다단계 논리 문제를 더 정확히 푼다 —
특히 표면 순서 함정(도치 질의)과 부정 질의에서.**

원안에서 교정된 점:
1. 입력은 세 모델 모두 자연어 — 원안은 파싱된 튜플이 검증기에 직접 입력되어
   난제(자연어→명제 추출)가 생략되고 SSM 출력이 미사용(장식)이었음.
2. 부정(¬)·모순을 검증기에 실제 구현 (지휘자 원안 뼈대 계승·리터럴 그래프로 확장).
3. "환각 0%" 표현 폐기 → 범주별 오답률 실측. 검증기 100%는 정의상 참(발견 아님)이며,
   오류는 전부 추출 단계에서 전파됨을 명시 측정.
4. O(N²) vs O(N)은 '알려진 수학의 실측 확인'으로 강등 표기 — 새 주장 아님.

## 사전 등록 킬 기준 (결과를 본 뒤 수정 금지)

- **K1:** 파이프라인의 함정 범주(도치+부정) 정확도가 최고 종단 베이스라인 대비
  **+10%p 미만이면 추출기 접근 기각**, 원인 분석서만 남긴다.
- **K2:** 어느 모델이든 전체 정확도가 다수결 베이스라인 이하면 학습 실패로 실험 무효.

## 설계

- 데이터: 합성 자연어 (엔티티 30종 × 규칙/질의 템플릿, 라벨은 리터럴 그래프 폐포로 기계 계산)
  - 범주: direct(직서) / chain(3홉+) / invert(도치 함정) / neg(부정)
  - train 3,374 / test 910 (설계 목표 3,000/800 · 라벨 균형 40~60% 보정 후 실측 — `out/results.json` n_train·n_test; 표기 정정 커밋 6cd336a)
- 모델 (전부 자작·순수 NumPy 자동미분, 의존성 0 — G3 재현성):
  1. Mini-Transformer 종단 (2블록 단일헤드 어텐션, d=48)
  2. SSM 종단 (2층 대각 선형 재귀 스캔, d=48)
  3. 추출기(SSM 인코더 + from/to/neg 3헤드) → 기호 검증기(부정 지원 DFS)
- 검증: `autograd.py` 수치 기울기 대조 통과 (오차 1.4e-10)

## 정직성 한계 (백서·그랜트 인용 시 필수 명기)

1. **토이 스케일** — 어휘 58·템플릿 문법. 실세계 문장으로의 외삽 근거 아님.
2. **감독 이점** — 추출기는 슬롯 감독(gold)을 받았고 종단 모델은 이진 라벨뿐.
   "분해가 값싼 중간 감독을 가능케 한다"는 것이 접근의 구조적 장점이지만, 공정 비교
   관점에서는 추가 정보임을 명시해야 함. 종단 에폭(12) < 추출기 에폭(40)도 동일.
3. 남은 병목 = 도치 문장 추출(0.936) — 오류의 전량이 신경 추출 단계에서 발생.
   "환각이 제거"된 것이 아니라 **환각이 측정·국소화 가능한 한 단계로 압축**된 것.
   이 국소화가 다음 단계(추출 오류에 담보·슬래싱 연결)의 전제 조건이다.
