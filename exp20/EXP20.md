# Exp20 — proofHash v0.4: 바인딩 닫은 증명 실린 판정 (심의 안전분만)

> 2026-08-27 · 심의(적군석 R2·R3 KILL / 메커니즘석 R1'~R7)의 안전 인증분을
> 구현. 핵심은 심의가 지목한 두 급소를 닫는 것:
>   (A) 바인딩: 증명이 특정 사건에 묶이지 않음(poseidon↔requestHash 오프체인).
>       → 사건 정체성 = 회로가 커밋한 입력 해시. requestHash == instances[0].
>   (B) 점수 미포함: 증명이 추출기만 덮고 점수 단계 안 덮음.
>       → 증명 인스턴스에 최종 점수 포함(instances[1]), 게이트가 온체인 강제.
> 그 위에서 R2'(결정론 사건 증명 최종)·R4(무허가 제출)·R5(무보상 상환) 구현,
> 게이트 결정 로직을 Halmos로 증명. 오버라이드-패널·소수파 슬래시는 미구현
> (게이트가 직접 정산하므로 상충표 자체가 없음 — 심의 KILL 회피).

## 사전 등록 킬 기준 (실행 전 박제)

- **K1 바인딩**: ∀ instances·requestHash — attest는 instances[0]==requestHash가
  아니면 revert. 엉뚱한 입력의 유효 증명으로 이 사건을 정산 불가(적군석 Attack1 봉쇄).
- **K2 점수 확정**: 정산되는 점수 == instances[1](증명 커밋). caller의 score 인자가
  instances[1]과 다르면 revert(적군석 Attack2 봉쇄 — 점수 위조 불가).
- **K3 단일·비소급**: 같은 사건 두 번 attest 불가, 정산 후 불변(Attack4 소급 봉쇄).
- **K4 무보상 상환**: 상환액 ≤ 상한이고 점수와 무관(결과 독립) → 정리 3 승자보상금이
  될 수 없음(R5). 유효 증명에만 지급(진실 게이트: 소ن드니스로 거짓 판정엔 증명 불가).

## 정직성 라벨

- halo2 검증자는 외부·검증됨 가정(Exp15/16 실물, 864k 가스). Halmos는 verify=true
  전제 하 게이트 결정 로직을 증명 — 게이트 안전은 검증자 내부가 아니라 "verify=true
  ⟹ instances가 커밋된 (입력해시, 점수)"에만 의존.
- 바인딩 기준: 사건 정체성 = 회로 커밋 입력 해시. keccak(원문)↔ids는 공개 결정
  토크나이저(오프체인, 감사 가능).
- 점수-인-증명: 회로 공개 인스턴스에 최종 결정론 점수 포함 가정. 현 Exp14/16 회로는
  로짓 출력 — 점수(기호 규칙 접기) 포함 확장은 회로측 후속 명기. 컨트랙트는 그
  인터페이스에 대해 증명됨.

## 결과 (2026-08-27) — K1~K4 전부 통과

`ZkVerdictGate.sol`(judge 자리) + `IZkVerifier`(외부·Exp15/16 실물). Halmos 5/5, Forge 6/6(전체 69/69).

| 킬 기준 | 증명 |
|---|---|
| K1 바인딩 | instances[0]≠requestHash → revert (∀). 엉뚱한 입력 증명으로 정산 불가 |
| K2 점수 확정 | score 인자≠instances[1] → revert. 정합 시 정산점수==instances[1] |
| K3 단일·비소급 | 두 번째 attest revert, 첫 판정 불변 |
| K4 무보상 상환 | 상환액=min(잔액,CAP), 점수 미참조 → 결과 독립(승자 보상금 불가) |

**의미:** 심의(적군석 R2·R3 KILL)가 지목한 두 급소를 **구조로** 닫았다 — 사건
정체성을 회로 커밋 입력 해시로 정의해 바인딩 완결(Attack1), 점수를 증명 인스턴스로
온체인 강제(Attack2). 그 위에서 R4(무허가)·R5(무보상 상환)·비소급 단일 정산을
구현하고 게이트 결정 로직 전부를 기계 증명. **오버라이드-패널·소수파 슬래시는
구현 안 함** — 게이트가 직접 정산해 상충표 자체가 없으므로 KILL 위험을 회피.

**정직성:** halo2 검증자는 외부·검증됨 가정(verify=true ⟹ instances=커밋된
(입력해시,점수); 실물은 Exp15/16 864k 가스). 회로가 최종 점수를 공개 인스턴스로
내도록 하는 확장은 회로측 후속(현 Exp14/16은 로짓). 상환 무보상성은 소ن드니스
논증(거짓 판정엔 유효 증명 불가)+컨트랙트 상한. score 0~100 도메인 제약.
