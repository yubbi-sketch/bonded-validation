## 사전 등록 킬 기준 (실행 전 박제)

- **K1 (성립성)**: 추출기 전체 순전파(문장 1개, T=14)의 증명이 이 노트북에서
  생성되고 검증에 성공해야 한다. 실패 시 → "현 툴체인으로 불가" 판정을 그대로
  등재 (부정 결과도 결과다).
- **K2 (실용성)**: 증명 생성 30분·검증 10초·피크 메모리 16GB 이내.
  초과 시 → "laptop-provable 주장 철회, 백서 §6 수정" — 백서에 이미
  "proving time unmeasured"로 헤지했으므로 백서 정정은 §6 수치 추가.
- **K3 (정확도)**: ezkl 양자화 회로의 출력 argmax(3헤드)가 float 순전파와
  샘플 20문장에서 일치율 ≥ 95%. 미달 시 → 스케일 파라미터 재조정 1회 허용,
  그래도 미달이면 "양자화 재학습 필요" 판정.

## 정직성 라벨

- 문장 1건 증명이다 — 처리량(초당 판정 수)·집계 증명은 범위 밖.
- ONNX는 손으로 구성(torch 없음): 스캔 루프는 T=14로 언롤. 그래프가 원
  NumPy 순전파와 동일함은 float 출력 대조로 확인한다(수치 오차 ≤ 1e-4).
- SRS는 공개 세리머니 파일 다운로드 — 신뢰 가정은 halo2/KZG 표준과 동일.
