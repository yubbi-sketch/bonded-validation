# Exp27 — 인간 정지·재개 권한 (EAL-X)

> 지능 불변 보안 연구 · 2026-08-28 · 오너 비전("사람이 멈출 수 있고 다시 시작할 수 있는")에서 출발

## 0. 첫 줄 (LOCK-0, 모든 산출물에 고정)

> 우리가 증명하는 것은 "AI가 멈춘다"가 아니라 **"온체인 권한이 소멸한다"**이다.
> 정지는 사고를 멈추지 않는다. **정산을 멈춘다.** 그리고 그것조차 '정지(pause)'가 아니라 **'소멸(lapse/revoke)'**이다.
> **우리는 '정지 권한'을 만들지 못했다 — 만들 수 없음을 증명했다.**

## 2. 폐기한 것 (적대검증 3렌즈 전원 BROKEN)

원안 **BHR(Bonded Halt Right)** 의 거의 전부: 정지보증금 H · 시간비례 소각 · 에스컬레이션 2^(k−1) ·
윈도 W · 역담보 즉시재개 R2 · 정지자 보상 R_h · 자율성 일몰 사다리 θ(n) ·
그리고 **"판정 없이 반-그리핑을 달성한다"는 주장 전부.**

그 사망진단서가 아래 불가능성 6종이다.

## 3. 불가능성 정리 — 이번 라운드의 실제 산출물

| 검사 | 내용 | 결과 |
|---|---|---|
| **I1b** | **Exp26 CORE-WS 완전 재현** — 정적 담보 하에서 가치-스케일 정지보상은 불가 (R_h≤B_ag ∧ R_h≥σV ∧ σV>B_ag) | **UNSAT** |
| **I2** | **이중모순 II** — 내생 판정자 없이는 (N)무손실 정직정지 ∧ (A)반-그리핑 동시 불가. **원인은 자금조달이 아니라 식별불가능성**: 지급함수가 정당/부당을 못 가리면 같은 관측이력에 ≥0과 <0을 동시에 요구하게 됨 | **UNSAT** |
| **I3a/b** | 시간선형 정지가격은 스텝형 그리핑 피해를 유계화 불가. ∀λ>0에 반례 Δt=σ/2λ가 존재하고 그 지점에서 비용<피해 | **UNSAT** |
| **I4** | 역담보 즉시재개(R2)는 데드락 방지 장치가 아니라 **정지 무력화 장치** | **UNSAT** |
| **I5a/b** | 에스컬레이션 윈도 딜레마 — W 유한이면 리셋으로 총 정지시간이 예산에 **선형**(로그 상한 거짓), W 무한이면 정직한 20회차 단가가 **524,288**로 폭발 | SAT 증인 |
| **I6** | 정합성 슬래시가 s_act를 선점하면 정지보상 V-스케일 불가 → **Exp26 "E2 탈출"의 정지판 적용은 철회** | **UNSAT** |

**I2가 MakerDAO ESM과 멀티시그 방식이 왜 각각 (N)과 (O)를 버렸는지 설명한다** — 어느 실물도 셋을 동시에 못 가졌다.

## 4. 남긴 것 — EAL-X 4층 (담보·소각·보상·투표 **전부 0개**)

- **L0 소멸(lapse) — 권한자 0명.** 권한은 만료 ε의 리스다. 아무도 아무것도 안 하면 죽는다.
  **인간 개입의 최소 형태는 "누르는 것"이 아니라 "안 누르는 것"이다.**
  → 무손실 기권(Exp2/5)의 직계는 '무손실 정지'가 아니라 **'무손실 부작위'**다.
- **L1 폐기(revoke) — `unpause` 함수가 존재하지 않는다.** 재개 = 원권리자의 **신선한 서명에 의한 신규 리스 발급**뿐.
  이로써 **재개 데드락이 개념적으로 소멸**한다(Moonwell 실패 모드가 표현 불가능해짐).
- **L2 거부권(veto) — 정지가 아니라 '주의(attention) 세금'.** 제3자는 정액 P로 **현 에폭의 갱신 1회만** 차단.
  실행을 못 멈추고, 자금을 못 묶고, 기존 권한을 못 죽인다. 효과는 오직 **"다음 갱신에 신선한 서명을 강제"**.
  에폭당 1회·연장 불가라 **OP/Aztec의 무한연장 결함이 구조적으로 재현 불가**(V3).
- **X 탈출차선** — 폐기 중에도 원권리자 인출이 생존하고(X1), 에이전트 키로는 우회 불가(X2, 수취인 고정이 필수조건).

## 6. 정직하게 못 하는 것 (전량 등재)

1. **★V2 — 온체인은 "신선한 서명"만 증명한다. "사람이 했다"는 증명 불가**(fresh_sig ∧ ¬human = SAT).
   제목이 '인간 정지 권한'이지만 실제 배달물은 **'지정 키의 신선한 서명 강제'**다.
2. **★A5 — 가장 싼 영구정지는 무료다.** 갱신키 강압·탈취·구금·분실 하나면 ε 후 권한이 죽고 **비용 상한이 없다.**
   원안의 "유한 예산으로 영구정지 불가"는 **가장 싼 경로를 모델에서 빼고 얻은 UNSAT**이었다 — 철회.
3. **★C4 — 지배적 누수:** 권한 있을 때 발급한 **선행 승인(ERC-20 approve·세션키·delegatecall)은 폐기 후에도 생존.**
   원안이 "증명한다"고 쓴 격자 커버리지는 **체크가 하나도 없었다.**
4. **S4 — 자동갱신이 fail-safe를 스스로 무력화**(원권리자가 갱신을 전부 자동화하면 lapse 기본값이 공허).
5. **S3 — 모듈이 전역 liveness 단일장애점.** 브릭 하나로 전 스코프 영구 소멸, 불변 배포라 복구 불가.
   원안이 이를 'fail-safe 미덕'으로 쓴 것을 **명시적 비용으로 재분류**.
6. **X3 — 정지는 수탁이 아니다(예외가 아니라 기본 사례).** 원권리자 키 침해 시 탈출차선이 곧 탈취로.
7. **X4 — 폐기 자체가 손실을 만든다(상한 없음).** 만기·헤지 롤오버·경매 마감은 죽고, 언와인드해 주지 않는다.
8. **C3 — 잔여창은 "≤1블록"이 아니다.** L2에선 시퀀서가 강제포함 창까지 지연 가능 → 창이 **시간 단위**.
9. **C5/A3 — 완전성은 권한 열거의 완전성만큼만.** 그리고 **레지스트라가 사실상 최고 권한자다.**
10. **C6 — 스코프 파편화가 선택압.** 루트 N개면 veto 비용 N·P, 에이전트 비용 불변 → **시간이 갈수록 나빠진다.**
11. **V1 — veto는 반-그리핑이 아니다.** 정액 P로 무계 피해 가능. **"그리핑 방지"라는 표현을 산출물 전체에서 삭제.**
12. **Exp24 교훈 재적용:** 공격자의 외부이득 G는 모델 밖 — 어떤 비용 상한도 억지력이 아니라 **가격표**다.
13. **자율성 사다리 없음.** θ(n) 일몰은 폐기(발화 sybil·자기서명 V_decl·세터 미명시).
14. **오너 자신의 배포 조건에선 L2가 거의 안 쓰인다.** "오너 외 사람 개입 없음"이면 정지는 L0(갱신 안 하기, 무료)로 충분하고
    veto는 제3자가 있을 때만 의미가 있다. **이 프리미티브의 신규 부분은 우리 스택에서 미사용 상태로 출발한다** — 숨기지 않는다.
