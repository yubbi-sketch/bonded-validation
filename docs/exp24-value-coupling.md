# Exp24 — Value-Coupling 스케일-억제 정리 (정리24-L)

> 지능 불변 보안 연구 · 2026-08-27 · 케이스 스터디가 강제한 신규 실험
> 설계+적대검증 워크플로우(5에이전트, 3렌즈) → z3 9/9 + 몬테카를로 시뮬.
> **정직 헤드라인: value-coupling은 BornTooLate를 "치료"하지 않는다.**
> 살아남는 것은 좁은 스케일-디커플링 제거뿐이며, 그 경계를 기계로 못박았다.

## 0. 동기와 결론 먼저

케이스 스터디([case-study-uma-borntoolate.md](case-study-uma-borntoolate.md))에서 예약한 신규 연구 ①.
문제: 정리2(매수 하한)는 공격자 이득이 프로토콜 **안**(≤B_a)일 때만 수익성을 억제한다.
BornTooLate처럼 이득이 **바깥 베팅**(G)이면 정리2는 침묵(가정 A5). 아이디어: 판정 담보를
분쟁 금액 V에 **결합**(B_j=κV)해 뒤집기 비용을 상금과 같은 차수로 키우자.

**적대검증 3렌즈가 원 아이디어를 크게 좁혔다**(경제 needs-scoping, 메커니즘 needs-scoping,
형식 **BROKEN**). 이 세션 4번째 자기교정이다. 살아남은 정직한 결과:

- ✅ **되는 것:** 유효범위 안에서 **스케일-디커플링 제거** — UMA식 상수담보가 "풀이 커질수록
  뒤집기 비용이 상금에 미달"하는 규모붕괴를, 결합 담보는 겪지 않는다.
- ❌ **안 되는 것(정직 강등):** value-coupling은 **BornTooLate 자체를 못 막는다.** 그 사건은
  (i) top-5 스테이커의 **결정론적 장악(p≈1)** 과 (ii) 판정 풀과 **분리된 외부 시장의 G** —
  둘 다 유효범위(H1·H5) 밖이다. 원 브리프의 "UMA 치료제" 프레이밍은 **철회**한다.

## 1. 정리24-L (LOCKED, 조건부 스코핑판)

**전제 H1–H7이 모두 성립하는 유효영역에서만** 주장한다.

- **주장 A (스케일-디커플링 제거 — 유일한 헤드라인).** 담보를 분쟁 풀에 결합(B_j=κV)하면,
  상수담보 메커니즘이 겪는 규모붕괴가 제거된다: κ가 임계 이상이면 뒤집기 비용이 상금과
  같은 차수(∝V)로 스케일한다.
- **주장 B(i) (위험선호-강건, H2 필수).** κ ≥ 1/(m(1−p_max)) 이면 보장벌칙
  m(1−p)B_j = m(1−p)κV ≥ V ≥ G — 어떤 매수예산으로도 회수 불가.
- **주장 B(ii) (위험중립, 정리2 정합).** κ ≥ p/(m(1−p_max)) 이면 Π_ext = pG − m(1−p)B_j ≤ 0.
- **대조 확증.** V-무관 상수 B_j=b0 에는 항상 m(1−p)b0 < V=G 인 V가 존재(UMA 규모붕괴 재현).
- **명시적 비주장.** BornTooLate/UMA 병리를 치료하지 않는다(H1·H5 위반).

**임계 수치(m=3):** D1 κ*=1/(3(1−p)) → p=0.5에서 **0.667**; D2 κ*=p/(3(1−p)) → p=0.5에서 **0.333**.
정직 주의: 0.667은 D1(보수적 최대상금 목표)이지 정리2 정합 위험중립 임계(0.333, D2)가 아니다.
두 임계 모두 p→1에서 발산 → H1이 없으면 유한 담보로 억제 불가.

### 유효범위 전제 (적대검증이 강제한 H1–H7)
| 전제 | 내용 | 강제한 렌즈 |
|---|---|---|
| **H1** p-상한 | p ≤ p_max < 1. **결정론적 장악(p≈1, BornTooLate)은 범위 밖** | 형식(critical) |
| **H2** 책임 내부화 | 공격자가 몰수비용을 확정 내부화(유한책임·차입후디폴트 배제) | 형식(critical) |
| **H3** 다수 미구성 | 참여상한 또는 "오류시 다수도 슬래시" — 자기-다수 zero-slash 봉쇄 | 메커니즘(critical) |
| **H4** V-무결성 | V는 조작저항 오라클(외부 결제가치/장기 TWAP), 순간 온체인 풀 아님 | 메커니즘(critical) |
| **H5** G≤V 유효범위 | 단일·격리·정적 complete-set 시장 — **외부 참조 파생·교차상관·bond-low/redeem-high 없음** | 경제·형식(critical) |
| **H6** 독립 m | 담보 상관/위임이면 실효 m'=m(1−ρ)<m 로 보수화 | 메커니즘(major) |
| **H7** 반사성 범위 | κV<C(판정자 자본) 유지되는 V<V_crit 에서만 — 초과 시 자기파괴 | 메커니즘·경제(major) |

정리24-L은 **정리2를 대체하지 않고 조건부로 확장**한다(H5 추가 요구 → 그만큼 약함). G≤V 다리를
제거하면 단순 비용하한으로 회귀한다.

## 2. z3 기계 검증 — 9/9 (`exp24/prove.py`)

같은 스크립트가 **성립(UNSAT)** 과 **붕괴 경계(SAT 증인)** 를 양방향 판정한다. 붕괴 증인은
"정리가 무적용이 되는 지점"의 정직한 문서화다.

| 검사 | 무엇 | 결과 |
|---|---|---|
| **z3-1** | D1 타당성: κ≥1/(m(1−p)) ⟹ 보장벌칙 ≥ 상금 | **UNSAT** (성립) |
| **z3-2** | D2 타당성: κ≥p/(m(1−p)) ⟹ 기대이익 ≤ 0 | **UNSAT** (성립) |
| **z3-3** | 하한 필요성: 과소결합이면 수익 공격 존재 | SAT (증인) |
| **z3-4** | **decoupled 규모붕괴**: 상수담보는 큰 V에서 상금 미달 | SAT (우리가 고치는 병리) |
| **z3-5** | 임계 무차별: κ=κ*에서 이익 정확히 0 → 엄밀부등호 필요 | SAT |
| **z3-6** | **H2 없으면 D1 붕괴**: 유한책임이면 사적 기대이익 pG>0 항상 | SAT (H2 승격 정당) |
| **z3-7** | **G>V 레버리지 붕괴**: 외부 참조 G=L·V(L>1)면 D1 임계에서도 깨짐 | SAT (H5 load-bearing) |
| **z3-8** | **p→1 억제불가**: 넉넉한 κ_max=5로도 p≈1이면 붕괴 | SAT (H1 필수) |
| **z3-9** | **V-오라클 조작 붕괴**: B_j=κ·V_measured인데 G가 V_true 추종 | SAT (H4 필수) |

실수 비선형(최대 4차) — nlsat 종결. z3-7·z3-8이 곧 **"BornTooLate가 유효범위 밖"의 기계 증명**이다.

## 3. 몬테카를로 시뮬 — 행동 반증 (`exp24/sim.py`, N=10⁴/셀, 시드 2026)

위험중립 모델: 실현이익 = [장악성공]·G − m(1−p)B_j. 순수 표준 라이브러리(numpy·matplotlib 무의존).

**주팔 (G~U(0,V], m=3, p=0.5) — 평균 공격자 이익:**
| V | 결합 D1 | 결합 D2 | decoupled(UMA, b0=$50k) |
|---|---|---|---|
| $100k | −74,796 | −24,982 | −49,969 |
| **$1M** | −755,032 | −243,968 | **+173,681** |
| $10M | −7,553,807 | −2,532,292 | +2,429,398 |
| $100M | −75,701,208 | −25,089,604 | +24,775,516 |

- **KC9 PASS:** 결합-D1은 **모든 V에서 이익 ≤0**(부트스트랩 CI 상단 포함).
- **KC3 PASS:** decoupled(UMA식)는 큰 V에서 흑자 전환 — 해석적 교차 **V*≈$300k**(0.25V=75k), 격자상 $1M에서 관측. **규모붕괴 실증.**

**경계팔 (결합-D1 위에서 유효범위 위반 → 예측 경계에서 붕괴 확인):**
- **KC5 레버리지** G=L·V: 예측 교차 L*=1/p=**2.0**. 실측 L=2.0에서 −3,800(≈0), L=2.5에서 +227,750 → **경계 일치.**
- **KC7 V-조작** B_j=κ·δ·V: 예측 교차 δ*=p/2=**0.25**. 실측 δ=0.25에서 −916(≈0), δ=0.125에서 +126,931 → **경계 일치.**
- **KC8 자기-다수:** 무패치(다수 슬래시0·p→1) +501,105 **뚫림**, 패치(다수도 슬래시) −749,628 **복구.**

시뮬은 "결합이 억제하는 곳"과 "그대로 뚫리는 곳"을 예측된 경계에서 동시에 못박는다.

## 4. 컨트랙트 (이번 라운드 범위 — 정직)

`ValueCoupledJudgePanel`은 **명세만** 하고 구현·Halmos는 다음 라운드로 유보한다. 이유(종합 연구원 권고):
대수 코어(D1/D2)는 z3로 종결됐고 두 줄 부등식을 Halmos로 기계화하는 건 theater다. 진짜 난제는
"전제 H1–H7을 컨트랙트가 강제할 수 있는가"라는 **메커니즘/불변식** 문제이지 정리증명이 아니다.

**불변식 명세(다음 라운드 구현·증명 대상):**
- **INV-1** value-coupling: 열린 분쟁 d마다 판정자별 bond = κ·V(d).
- **INV-2** V-무결·시점(H4·H5c): V는 조작저항 오라클·상환시점 판독, 담보 후 complete-set 발행 동결/동적 top-up.
- **INV-3** 참여상한(H3): 단일 엔티티가 ≥m 석 점유 불가 — **이 안전성만 Halmos 값어치(다음 라운드).**
- **INV-4** 슬래시 규칙(H3): 사후 오류 확정 평결은 소수편만이 아니라 **다수도 슬래시**.
- **INV-6** 스코프 가드(H5): 외부 참조 파생이 등록된 평결은 OUT-OF-SCOPE 플래그(정리 무보장).
- 가정 경계(온체인 강제 불가·문서화만): **H2**(차입후디폴트), **H1**(p≤p_max), **H7**(V<V_crit).

## 5. 정직성 한계 (전량 등재)

1. **BornTooLate 미해결** — Exp24를 동기화한 바로 그 사건을 못 고친다(H1·H5 위반). "UMA 치료제" 철회.
2. **G>V 붕괴군** — 외부 참조 파생(CDS/옵션/OTC)·교차마켓 상관·bond-low/redeem-high·비화폐 동기.
3. **p→1 미해결** — 결합은 비용 승수만 키울 뿐 장악확률 p 자체를 못 낮춘다.
4. **기대비용의 성격** — m(1−p)B_j는 확정비용 아닌 기대값. 유한책임·반복게임·조건부 성공확률이면 실효 하한 약화(κ*는 낙관 하한).
5. **반사성 DoS/중앙화(H7)** + **V-오라클 새 공격면(H4)** + **상관 정족수 붕괴(H6)** — 결합은 억제를 공짜로 주지 않고 새 공격면을 대가로 지불한다.
6. **D1(0.667) vs D2(0.333) 분리** — 위험선호를 정당화하지 않는 한 0.667을 "그 수"로 제시하면 강건성 과장. 임계 무차별은 엄밀부등호/ε-마진으로 배제.

**이 실험이 다음에 강제하는 것:** BornTooLate형(외부 참조·p≈1)을 실제로 다루려면 value-coupling이
아니라 **② 담보된 명세(bonded specification)** + **노출 결합(exposure-coupling, 단일 풀이 아니라 그
평결이 상환시키는 전 노출의 집계)** + **패널 장악확률 p 자체를 낮추는 선정 메커니즘**이 필요하다.
