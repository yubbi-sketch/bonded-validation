# Exp25 — 담보된 명세 (Bonded Specification)

> 지능 불변 보안 연구 · 2026-08-27 · 케이스 스터디가 강제한 신규 실험 ②
> 설계+적대검증 워크플로우(5에이전트·3렌즈, 전부 needs-scoping) → z3 탐지층 14/14.
> **정직 헤드라인: 담보된 명세는 사건 B를 "해결"하지 못한다.** 오직 형식화 가능한 좁은
> 슬라이스만 자금 전에 표면화하며, z3-9(UNSAT)가 그 무능의 기계적 증거다.

---

## 0. 동기와 결론 먼저

사건 B(Strategy BTC 매도 시장, $80M+): "5/31까지 매도"가 **event-time**(매도 발생)인가
**disclosure-time**(공시)인가라는 **결의 기준의 정의 모호성**. 판정 슬래시로는 못 고친다 —
정답이 명확해야 벌하는데 정의 자체가 미정. 아이디어: 결의 명세를 술어로 형식화해, 자금 유입
**전에** 모호성을 기계 탐지하고 저자 담보에 걸어 표면화·가격화한다.

**적대검증 3렌즈(의미·메커니즘·경제)가 전부 needs-scoping을 냈고, 원 주장을 크게 좁혔다** —
이 세션 **5번째 자기교정**. 살아남은 정직한 결과:

- ✅ **되는 것(좁게):** *형식화 가능한 좁은 슬라이스* — 저자가 **열거한** 해석집합 안의 crisp
  해석쌍 불일치 + UNDEFINED — 를 자금 전에 표면화·가격화한다. 이 슬라이스엔 기계적으로 강함.
- ❌ **안 되는 것(정직 강등):** **사건 B 자체를 못 고친다.** 그 사건엔 매도시각의 **독립 오라클이
  없어** event-pin이 disclosure-pin과 분리되지 않는다(**z3-9 UNSAT** = 못박기가 공허). 게다가
  "매도"의 **지배적** 모호성은 타이밍이 아니라 **술어수준**("질권/대차/선도도 매도인가", z3-10 SAT)
  이라 열거 밖이다. value-coupling(Exp24)이 BornTooLate를 못 고쳤듯, 이 층도 사건 B를
  **표면화 대상으로 좁게 재정의**할 뿐 소멸시키지 않는다.

## 1. 메커니즘 (LOCKED)

명세층(판정층 아님). 흐름:
1. **COMMIT** — 저자가 결의 명세 R을 술어 DSL로 온체인 커밋. `spec_hash = H(dsl, Ω, I, comparator_flags)`.
   결정가능 도메인 **Ω**와 **명시 열거 해석집합 I**를 함께 커밋(둘 다 담보 대상).
2. **BOND** — 담보 B_spec 예치(개설 게이트 전제).
3. **CHALLENGE WINDOW** — `commit_block + Δ_challenge` 동안 시장 개설·자금유입 escrow-lock(Δ는 프로토콜 상수, 저자 단축 금지).
4. **WITNESS** — 도전자가 기계검증 증인 ω*∈Ω 제출: (A) 열거된 두 해석 불일치, 또는 (B) R(ω*)=UNDEFINED.
   `verifyWitness`는 **반드시 ω*∈Ω_committed 멤버십을 먼저 확인**(건전성) 후 DSL 순수 재실행.
5. **SLASH+GATE / CLEAR** — 유효 증인 → B_spec 슬래시 + 영구 REJECTED. 무증인 종료 → 개설 허용.
   개정은 spec_hash 변경으로 창 리셋(개정으로 창 회피 불가).

**모호성 정의(기계 검증):** R·Ω·I가 주어질 때 **AMBIGUOUS** ⟺ ∃ω*∈Ω: (A) ∃r_i,r_j∈I reading_i(ω*)≠reading_j(ω*),
또는 (B) ∃r_i reading_i(ω*)=UNDEFINED. **UNAMBIGUOUS** ⟺ 그런 ω* 부재. 못박기(I를 싱글턴화 + 정의역 가드)가
(A)/(B)를 논리적으로 소거.

## 2. z3 탐지층 기계 검증 — 14/14 (`exp25/prove.py`)

같은 스크립트가 **닫힘(UNSAT)** 과 **모호·경계(SAT)** 를 양방향 판정한다.

| 검사 | 무엇 | 결과 |
|---|---|---|
| **z3-1** | 미명세 I={event,disclosure}, Strategy 세계 → 두 해석 불일치 | **SAT** (사건 B 타이밍 모호성 재현) |
| **z3-2** | event-time 단일 해석으로 못박음 | **UNSAT** (무모호) |
| **z3-3** | 파일링 부재 → R=UNDEFINED | **SAT** (구멍) |
| **z3-4** | disclosure-time 단일 해석(대칭) | **UNSAT** (무모호) |
| **z3-5** | 열거밖 제3해석(settlement-time) | **SAT** (정직 경계) |
| **z3-6** | 비교자 ≤ vs < 가 event==deadline에서 갈림 | **SAT** (포함성 축) |
| **z3-7** | 총함수 가드(disc⇒filing) | **UNSAT** (UNDEFINED 닫힘) |
| **z3-8** | event_time 측정 두 오라클 불일치 | **SAT** (측정층·판정담보 소관) |
| **z3-9** | **독립 오라클 없이 obs_event==disclosure → event-pin ≡ disclosure-pin** | **UNSAT** (**사건 B 못 고침의 기계 증거**) |
| **z3-10** | 타이밍 못박아도 '질권을 매도로 치나' | **SAT** (**사건 B의 *지배적* 모호성**) |
| **z3-11** | gradable threshold τ 커밋 | **UNSAT** (닫힘) |
| **z3-12** | threshold 미커밋(t1<t2) | **SAT** (연속체 누출) |
| **z3-13** | Ω 멤버십 미검증 → 정직 저자 false-positive | **SAT** (불건전) |
| **z3-14** | 검증자가 ω*∈Ω 멤버십 강제 | **UNSAT** (건전성 회복) |

**6 UNSAT(닫힘/무능) + 8 SAT(모호/경계).** z3-9가 이 실험의 핵심 — "그냥 event-time으로 못박으면
되잖아"가 사건 B에선 **공허**함을 증명한다(관측 자체가 공시를 통하므로 두 pin이 동일 함수).

## 3. 검증 상태 — 무엇이 증명됐고 무엇이 안 됐나 (정직)

**기계 검증된 것:** z3 **탐지층 14개 명제뿐**. 이건 "탐지 명제가 이 추상 정수 모델에서 모순 없다"는 뜻이지
"메커니즘이 안전하다"가 **아니다.**

**미검증 산문(다음 라운드 필수 관문):**
- **컨트랙트 불변식 INV-1~10**(개설 게이트·슬래시 원자성·무보상금·회계 보존·Ω 멤버십·개정 DoS 상한) —
  Foundry+Halmos 심볼릭 실행 **미실행**. **KILL-6(개설 게이트 우회 부재)은 이번 라운드 미달성.**
- **KILL-5 인센티브 딜레마 — 미해결(강등으로만 통과):** 도전자 보상을 시장규모에 결합하면 wash 공격
  (couple→wash), 상수화하면 free-rider 과소공급(decouple→탐지 붕괴). 무보상금(INV-3)은 wash를 막지만,
  **정확히 고가치 시장에서 탐지가 baseline에 근접**한다. 균형에서 이 메커니즘은 주로 "저자가 정직해서
  필요 없었을 때" 모호성을 표면화한다.

## 4. 정직성 한계 (전량 등재)

1. **★사건 B 미해결(z3-9):** 실제 매도시각의 결의용 독립 오라클이 없어 event-pin이 disclosure-pin과
   분리되지 않는다. "그냥 못박으면 된다"가 이 사건에선 공허.
2. **지배적 모호성은 열거 밖(z3-10·z3-5):** "무엇을 매도로 치나"(질권·대차·선도·칼라)의 술어수준·미열거
   해석이 사건 B의 실제 핵심. 설계가 다루는 타이밍축은 소수 슬라이스.
3. **I 과소열거는 저자의 지배전략**(순진한 엣지케이스 아님). 저자는 유리하게 결의하려 I를 좁게 낸다.
   I-확장 구제는 "R_k가 admissible 해석이냐"라는 **NL 판정을 재도입**(신뢰점 회귀).
4. **인센티브 딜레마 미해결**(§3, KILL-5).
5. **Liveness/검열:** 풍부한 실제 명세는 거의 항상 어떤 유효 증인(비교자·tie-break·UNDEFINED 엣지)을
   허용 → 전략적 적이 비호감 시장을 증인으로 차단 + revise-리셋 반복 지연 DoS.
6. **재배치된 신뢰점:** NL→DSL 형식화(저자 수행)·인터프리터 2차 시맨틱(⊥-전파·비교자 포함성 z3-6·
   타임존·tie-break)은 그 자체로 모호할 수 있는 별도 명세. 단일 해석 내부 under-definition은 pairwise 불가시.
7. **오라클 측정분쟁(z3-8)은 별 층**(판정 담보 Exp13/24 소관, 이 메커니즘 아님).

## 5. 이 실험이 강제하는 다음 (사전 등록)

- **다음 라운드 필수:** INV-1~10을 Foundry+Halmos로 검증(KILL-6 달성) — 특히 INV-1(개설 게이트 우회 부재)·
  INV-2(슬래시 원자성)·INV-10(Ω 멤버십). 이게 없으면 "사전 표면화" 전제 자체가 미검증.
- **인센티브 재설계:** ✅ [Exp26](exp26-incentive-dilemma.md)에서 **집행 완료(z3 19/19).** KILL-5는
  조건부 **이중모순**(반-wash R≤B_spec ∧ 가치-스케일 R≥σV, 몰수자금 조달이면 형태 무관)으로 판명 —
  스칼라·난이도연동·복권 모두 못 벗어남(FORFEIT-INV). 전문 감사자 스테이킹은 **relabeling**(정리2 재적용).
  **유일한 진짜 탈출**: V-스케일을 도전자 보상이 아니라 *공격자 공격시점 담보*에 부과(E2, 관측가능성 게이트).
- **술어수준 모호성:** 타이밍이 아닌 "무엇을 X로 치나"의 온톨로지 커밋 — z3-10이 강제. 이게 사건 B의 본체.

**두 실험 연속 정직 배당:** Exp24(value-coupling)는 BornTooLate를, Exp25(bonded spec)는 사건 B를 —
**둘 다 동기가 된 실제 사건을 "해결"하지 못하고 좁은 슬라이스만 다룬다**는 것을 기계로 못박았다.
과장하지 않는 것 자체가 이 연구의 산출물이다.
