# Exp8 설계서 — 판정자 담보·loser-pays (승격 전 공격 검증)

> 2026-08-26 · 심의 결정 C의 B-트랙: 구현 전 설계·공격 시뮬레이션 계획만 먼저 확정
> 상태: **설계 단계 — 오너 "가" 전 구현 착수 금지**

## 가설

**"반대표에도 가격을 붙이면(판정자 담보 + 확대재판 소수파 몰수) 괴롭힘 비용이
0에서 양수가 되어, v0.1의 잔여 리스크(공짜 반대표로 시간상한 동결)를 없앨 수 있다."**
선례: UMA 낙관적 오라클 — 분쟁 제기자도 동일 담보 예치, 패자가 문다(loser pays),
수년째 실전 가동. 단 UMA의 최종심은 토큰 홀더 투표(DVM)로 우리에겐 없는 자원.

## 설계 스케치

- 판정자는 8004 신원 등록 + 판정자 담보 예치 후에만 패널 참여 (BondedValidator
  재사용 — 판정자도 "발화자"다: 판정이 곧 담보 잡힌 발화)
- 반대표 발생 → 확대재판 5인(무작위 추출) 재실행 → 소수파 판정자 담보 몰수,
  몰수분 일부는 동결 피해 에이전트에게 보상(잠김 비용 배상)
- 판정자 평판 = ReputationLens 재사용 (판정 이력이 신용, 신용이 담보 할인)

## 심의가 박은 급소 (통과해야 할 킬 기준)

- **K1 다수 매수 역공격**: 5인 중 3인 매수 시 정직 판정자가 역슬래싱되는 비용/성공률
  시뮬레이션 — 공격 비용이 방어 가치보다 크지 않으면 기각
- **K2 시빌 판정자**: 신참 판정자 다수 등록으로 확대재판 오염 — 신참 할증(렌즈
  1.5×)과 추첨 가중이 막는지 실측
- **K3 "소수=틀림" 미증명 문제**: 결정론 범주 한정 + 재실행 스크립트 공개로
  사후 검증 가능성을 만들되, 온체인 증명은 아님을 명시 (완전 해소는 P3 zkML)
- **K4 타임아웃 직전 스팸**: 분쟁 대량 생성으로 확대재판 큐 마비 — 분쟁 제기
  담보가 큐 비용을 감당하는지

## 승격 조건

K1~K4 시뮬레이션 전부 통과 + Forge 테스트 → v0.2로 승격, 오너 상급심(훈련바퀴) 제거.
하나라도 실패 → v0.1(시간상한 환급) 유지가 결론이며 그것도 유효한 연구 결과다.
