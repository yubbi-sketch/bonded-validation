# Exp28 — 심판은 왜 정직한가 (게으름·뒷돈)

> z3 9/9 통과 (직접 실행 확인). 재현: `.venv-halmos/bin/python exp28/prove.py`
> exp8(판정자 담보, 몬테카를로)이 남긴 두 구멍 — 게으름·외부매수 — 을 정면으로.

## 질문
심판은 왜 정직하게 판정하나? ① 게으름(정액 수수료만 받는데 왜 꼼꼼히?) ② 뒷돈(체인 밖 현금 매수).

## 결론 (푼 것 / 못 푼 것)
**푼 것 — 재검증 가능한 주장에선 심판 정직성이 아예 필요 없다.**
- A1 [THM]: 재실행자가 있으면 틀린 판정은 반드시 탐지된다. 정확성이 심판 정직성과 **독립**(unsat).
- A3 [THM]: 매수해도 재실행이 정답으로 정정 + 무보상금 → 매수자 순이익 = −b < 0. 뒷돈 무익.
- A4 [THM]: 게으르면(f 안 돌림) 슬래시 회피를 보장 못 함 → 유일 안전전략 = 실제로 검사기 실행.
- ⇒ 심판을 '재실행 가능한 검사기'로 대체하면 게으름·뒷돈 문제가 소멸.

**못 푼 것 — 주관적(재검증 불가) 주장.**
- B1·B2 [WIT]: 온체인 관측신호가 동일한 '매수-오판' 세계와 '정직-정답' 세계가 공존(sat). 뒷돈·게으름 **원리적 탐지 불가**.
- B3 [ENC]: 온체인 규칙은 관측 O만 읽는다 → 동일 O에 다른 슬래시 불가. 규칙이 못 보는 건 못 막는다.
- C2 [WIT]: 무보상금은 수익매수만 차단, 파괴매수(경쟁사 해코지)는 비용만 부과.
- ⇒ 이 영역엔 기계적 해법 없음(셸링점·평판 등 비-기계 영역).

## 제품 함의 (핵심)
정음/세종을 태워라는 **재검증 가능 주장에만 담보를 건다** — 발화 10선이 이미 그 규율이었고, 이제 그게 임의 선택이 아니라 **정리로 정당화**됐다. 주관적 판정에 담보를 거는 경쟁자(Kleros류)는 B의 불가능성을 물려받는다 = **우리 차별점의 수학적 근거**.

## 사전등록 킬 기준 (전부 통과)
- KILL-A 생존: 재실행이 정직성을 대체(A1 unsat).
- KILL-B 확정: 뒷돈 탐지불가(B1 sat).
- KILL-C 생존: 무보상금 계승(C1 unsat).
