## 0. 첫 줄 (LOCK-0, 모든 산출물에 고정)

> 우리가 만드는 것은 "환각을 수학으로 없애는 장치"가 아니라 **"모를 때 묻는 행위에 값을 매기고, 그 물음이 남의 정산을 1초도 멈추지 못하게 하는 규칙"**이다.
> 되묻기(ask)는 기권의 하위 행위다 — 담보 0, 판정 없음, 보상 없음. 되묻고 난 뒤의 답은 **새 주장·새 담보·새 시계**다.
> 임계 τ\* = B/(B+R)는 우리 것이 아니다 — Chow(1970)의 기각 규칙을 담보 언어로 다시 쓴 것이다([THM] C1). 우리 것은 셋의 교집합뿐이다: (a) 담보 시장 안의 무손실 1급 질문 행위, (b) 질문이 계류 정산을 못 멈추고 새 발화만 연다, (c) 질문·기권의 정당성을 게이팅한다.

## 3. 메커니즘 (이 렌즈가 확정하는 부분 — 기제 렌즈 R1~R10 와 정합, 충돌 항목은 §8 에 표기)

행위자: 발화자 S(Exp1 추출기+검증기, 주장당 담보 B) · 상대 C(질문을 낸 사람/에이전트) · 판정기 J(재실행 가능 검사기, Exp28 A1) · 체인(BondedValidator v0.3 + Exp30 창 W). 기호: p 보정 정답확률, R 정답 보상, B 담보, c 되묻기 비용(κ), δ 상대 응답확률, n_max 되묻기 상한, d 왕복 시간.

- **R1 3분할.** 질의 x 마다 `ANSWER`(담보 주장) / `ASK`(명료화 질문) / `ABSTAIN` 중 하나. 규칙은 §4.4.
- **R2 ASK 는 기권.** 규격 v0.1 §2.1 의 `check_id` 없는 주장과 동일 — 담보 0·판정 없음·보상 없음·슬래시 불가. 온체인 함수 아님(체인 선택).
- **R3 무보류.** 어떤 ASK 도 계류 주장의 `claimedAt`·W·`engaged`·T_max 를 바꾸지 못한다. 이미 주장한 h₀ 는 제 시계대로 정산, 되묻고 나면 h₁ 새 주장. 소급 명료화 없음.
- **R4 비용은 묻는 쪽.** c 는 소각 또는 0(가스만). 상대·판정기에게 지급 없음(정리 3·Exp26 A1). **담보에서 떼지 않는다**(기제 렌즈 Z7: 떼면 τ\* 가 내려간다).
- **R5 유계 루프.** 컨텍스트당 ASK ≤ n_max(잠정 2), 동일 질문 반복 금지, parent 해시 체인.
- **R6 답은 상대의 서명 커밋.** 해석을 **상대가** 못박는다(Exp25 한계3 의 반대 방향). 무응답(d_max) → ABSTAIN, 상태 변화 0.
- **R7 재발화는 새 주장.** h₁ = H(context ⊕ ask ⊕ answer ⊕ claim). J 는 핀된 입력으로 재실행. 새 B·새 `claimedAt`·새 W.
- **R8 확신도 공개(이 렌즈의 추가 제안, 오프체인).** ASK·ANSWER 레코드에 §4.2 측도 u 와 표적 슬롯·Δ 를 서명 포함. 체인은 읽지 않는다(Exp28 B3 존중). 검증자는 (i) Exp16 공개 인스턴스(로짓 62)로 u 를 재계산해 "ASK 가 정당했다"(Δ·(B+R) > c)를 **모델 바인딩 하에** 확인할 수 있다 — 회로 무수정, 이번 라운드 인터페이스만(§4.6). 기제 렌즈의 기호 판별 `legit`(non-vacuous over I)과 **상호보완**: 열거가 있으면 기호로, 없으면 로짓으로.
- **R9 판정 가능성 게이트.** 핀 후에도 등록 `check_id` 로 환원 안 되면 ABSTAIN.
- **R10 평판.** ASK 는 `answered`·`abstains` 에 안 들어간다(Exp30 §14.8 validator 필터 정합). 별도 `askRate` 노출(Exp6 원칙), 점수 가감 없음.

## 4. 수학

### 4.1 기본 게이트 = Chow(1970)의 재표기

V(p) = p·R − (1−p)·B, 기권 0. 답변 ⟺ p ≥ τ\* = B/(B+R). Chow: 정답 0·오답 c_e·기각 c_r 비용, 기각 ⟺ p < 1 − c_r/c_e. 정답 +R 기준 상대 손실 c_e = B+R, c_r = R ⇒ 1 − R/(B+R) = τ\*. **[THM] C1**(`prove_gate.py`). 우리 계산이지 Chow 원문 인용 아님.

### 4.2 불확실성 측도 4종 (추출기 헤드 q_{i,h} ∈ Δ(V_h), h ∈ {from,to,neg}, 문장 i)

- **u₁ 최약고리(Exp2):** c₁ = min_{i,h} max_v q_{i,h}(v)
- **u₂ 엔트로피:** c₂ = 1 − max_{i,h} H(q_{i,h}) / log|V_h|
- **u₃ 슬롯 마진:** c₃ = min_{i,h} [q^{(1)}_{i,h} − q^{(2)}_{i,h}]
- **u₄ 답 뒤집힘(검증기 인식, 이 렌즈 신규):** 파스 Z^{(k)} ~ Π q_{i,h}, K=64; â = mode_k verifier(Z^{(k)}); **c₄ = (1/K) Σ_k 1[verifier(Z^{(k)}) = â]**. 방해 규칙의 불확실성은 답을 안 바꾸므로 c₄ 는 높게 남는다 — 기호 검증기가 있어서 가능한 측도.

u₁~u₃ 는 Cole/CLAM 계열 표준, u₄ 는 Cole 의 반복도를 검증기 위에서 정확히 계산한 것. **주 측도는 u₄, 나머지는 비교(K1 이 고른다).** 기제 렌즈는 u₁ 을 확신 신호로 고정했다 — 충돌이 아니라 이 렌즈가 "u₁ 이 u₄ 에 지는가"를 K1 로 묻는 것.

### 4.3 되묻기 표적 = 슬롯 정보가치 (SAGE EVPI 의 검증기 버전)

슬롯 j=(i,h) 를 v 로 핀했을 때 c₄(Z | z_j=v) 재계산, **Δ_j = Σ_v q_j(v)·c₄(Z | z_j=v) − c₄ ≥ 0**. 표적 **j\* = argmax_j Δ_j**, 질문은 슬롯 템플릿 렌더(후보는 컨텍스트 엔티티 또는 극성 2값). 단순화 모델(슬롯 독립·완전 해소, p ≈ Π_j ρ_j)에서는 p⁺ = p/ρ_{j\*} 이므로 j\* = argmin ρ_j — **Exp2 최약고리가 표적 선택기로 재등장** [THM] C4b.

### 4.4 3분할 결정 규칙 (유한 지평, 실험은 1단계 룩어헤드)

V_ans(p) = pR − (1−p)B · V_abs = 0 ·
**V_ask^{(k)}(p) = −c + δ·Σ_v q_{j\*}(v)·max{V_ans(p⁺_v), 0, V_ask^{(k−1)}(p⁺_v)}**, V_ask^{(0)} = −∞ (무응답 1−δ 이면 0: 잠긴 것이 없다).
행위 = argmax{V_ans(p), 0, V_ask^{(k)}(p)}, 동률은 ABSTAIN.

닫힌 형(완전 해소 p⁺ = p/ρ_{j\*}, `prove_gate.py`, z3 4.12.6):
- **[THM] C2 바닥:** ASK 옵션 값이 무엇이든 ANSWER 가 선택되면 p ≥ τ\*. **되묻기는 답변 임계를 못 낮춘다** — Exp18 K2 보존 근거(기제 렌즈 Z4 와 같은 정리, 다른 인코딩).
- **[THM] C3 되묻기 후 임계:** p < τ\* 에서 "묻고 답함" > 기권 ⟺ p⁺ > τ\* + c/(B+R)(δ=1). δ 를 넣으면 τ\* + c/(δ(B+R)) — 기제 렌즈 Z3 와 일치.
- **[THM] C4 묻기 vs 지금 답하기:** p ≥ τ\* 에서 묻는 게 이득 ⟺ (p⁺−p)(B+R) > c ⟺ p(1/ρ_{j\*} − 1)(B+R) > c.
- ASK 영역은 τ\* 주변의 **구간**: 아주 낮으면 물어도 τ\* 못 넘어 기권, 높으면 답변 지배. 유효 답변 임계 τ\*_eff ≥ τ\*, k=0 에서 τ\* 복귀. (R,B)=(1,5): τ\*=0.8333, c=0.05·δ=1 → τ\*_ask=0.8417(기제 렌즈 `policy.py` 와 동일 수치).

### 4.5 지연·정산

NEW(우리): 정산 시각 ≤ t_claim + T_max, ASK 수 n 과 무관 **[ENC] N1**. HOLD(A2A 류): T = T_max + n·d, 무계 **[WIT] H1**. §6 K3 가 시뮬로 실측.

### 4.6 확신 공개의 결정가능성

**[WIT] M1:** 자기 신고 p̂ 만 보는 게이트는 낚시 ASK(진짜 p ≥ τ\*)와 정직 ASK 를 구분 못 한다(Exp28 B3 재현). **[ENC] M2:** p̂ ≡ p 강제(Exp16 바인딩)면 정당성 술어 Δ(B+R) > c 는 공개값의 함수 → 결정가능. 회로 무수정, 인터페이스만.

## 6. 킬기준 K1~K4 (사전등록 — 이 커밋으로 박제, 결과 보고 후 수정 금지)

**K1 측도 판별력 — 추출기 불확실성으로 되묻기 표적을 고를 수 있는가.**
양성 = `ambig_slots ≠ ∅` ∧ 답 유관(`answer_relevant`: 후보값들 사이에서 검증기 답이 갈림). 측도 4종 중 최선이
(a) 양성 탐지 AUROC ≥ **0.90**, (b) n_max=1·c=0.05 에서 게이트가 ASK 한 예제 중 표적 j\* ∈ ambig_slots ≥ **0.80**.
하나라도 미달 → **KILL**: "추출기 불확실성 = 되묻기 표적" 명제 기각, Exp2 맹목 기권만 남긴다(기제 렌즈의 '열거 I' 가정 없이는 안 된다는 뜻). `dialect` 미학습 템플릿 ASK 율 ≥ 30% 면 "측도가 학습 부족과 결정 불가를 못 가른다" 정직 라벨(킬 아님).

**K2 되묻기 1회의 가치 — Chow/WALLA 대조.**
같은 측도·(R,B)=(1,5)·오답률 상한 0.5%(Exp2 K1 계승)에서
(a) coverage(n_max=1, c=0.05) − coverage(n_max=0) ≥ **+15%p**, (b) 최적 τ 담보점수(n_max=1, c=0.05) **>** 최적 τ 담보점수(n_max=0).
미달 → **KILL**. c=0.2 에서 순서 뒤집힘은 보고만. Reality.eth 팔과 커버리지 차 < 5%p 면 "명료화 **내용**이 효과의 원천" 문장 철회(킬 아님). δ=0.8 행 박제(이득은 δ 조건부).

**K3 지연 공격 균형 — HOLD 대조 + 바닥 정리.**
(a) NEW: 모든 주장·모든 ASK 열에서 정산 시각 ≡ t_claim + T_max(시뮬 전수 + [ENC] N1). 예외 1개 → **KILL**.
(b) [THM] C2 UNSAT 아니면 → **KILL**.
(c) HOLD 대조: 지연자 실현 슬래시율 ≥ **20%** 감소 또는 도전자 자본 잠금 ≥ **2배**. 안 나오면 "보류는 지연 공격을 연다" 는 **이 시뮬에서 미실증** — 메커니즘 킬 아님, §0·§4.5 문장 강등, R3 정당화는 Exp25·27 인용에만 의존한다고 명기.
(d) 정직 되묻기형의 NEW 부 ≥ HOLD 부 − c·ASK 수. 위반 → **KILL(재설계)**.

**K4 공격면 상한.**
(a) 낚시: 모델 없는 공격자(무작위 파스, n_max=2 만큼 묻고 답함) 정확도 ≤ 정직 파이프라인 − **30%p**. 미달 → n_max=1 재측정, 그래도 미달 → **KILL**(되묻기가 모델을 대체 = 정보 누출).
(b) 바인딩 확신에서 부당 ASK(Δ(B+R) ≤ c) 수락률 = **0**(정확히). 자기 신고에서는 보고만(기대 100%, [WIT] M1).
(c) 어떤 ASK 도 토큰을 옮기지 않는다(구조·[ENC]). 위반 → **KILL**.
(d) 상대의 어떤 전략(거부·오답·모호 프롬프트 3종)도 정직 발화자의 기대 부를 **기권 전용 기준선 아래로** 못 내린다. 내리면 → **KILL**.
