## 0. 첫 줄 (LOCK-0)

> 되묻기는 **담보를 거는 행위가 아니라 담보를 걸지 않는 행위**다 — 기권의 하위 유형이다(규격 v0.1 §1).
> 되묻기는 계류 중인 어떤 담보 주장의 정산도 **멈추지 못한다**. 오직 **새 발화(새 주장·새 담보·새 시각)** 만 연다.
> 그래서 되묻기의 가격은 발화자의 시간·가스와 상대의 주의뿐이고, 프로토콜은 질문에도 응답에도 **한 푼도 주지 않는다**.
> 우리가 바꾸는 것은 임계 τ\* 가 아니다(그건 Chow 1970 의 규칙이고 Exp18 은 그 창발 실증이다). 우리가 바꾸는 것은 **불확실성의 좌표**다 — 스칼라 p 하나를 (능력 κ, 의도 확정도 w̃) 두 축으로 쪼개, "모른다"(기권)와 "무슨 뜻인지 모른다"(되묻기)를 갈라 가격을 붙인다.

## 2. 메커니즘 (LOCKED — 팀장 합성에서 다른 렌즈와 병합)

기호: B = 발화 담보(minBondPerClaim), R = 정답 보상, τ\* = B/(B+R), c = 되묻기 1회의 발화자 비용(가스·지연·기회비용, **담보 아님**), α = 상대의 응답 확률, ν = 상대가 "해당 없음"을 고를 확률, k_max = 되묻기 횟수 상한.

**R0 행위 3분할.** 발화자의 행위 집합은 {ANSWER, ABSTAIN, ASK}. ASK 는 ABSTAIN 의 하위 유형이다 — 담보 0·판정 대상 아님·보상 0·토큰 이동 0. (규격 v0.1 §1 "판정 불가 주장은 담보 대상이 아니라 기권 대상"; ERC 초안 불변식 2 "기권은 담보를 줄이면 안 됨"; Halmos T1 그대로.)

**R1 되묻기 레코드 `clarification/v0.1` (오프체인 서명, chain-optional §4).**
```
{ type, id, speaker, context_hash,        # 질의 원문 해시 — 계류 담보 주장 id 가 아니다
  readings: [r_1..r_m],                   # 기계 형식 해석집합 I (예: 추출기 슬롯 삼중 (from,to,neg))
  none_option: true,                      # 필수 — "어느 것도 아님"
  ambiguity: {w_tilde, kappa},            # 선택 — §3.6 zk 확장 시 공개 로짓과 바인딩
  round: k (1..k_max), asked_at, sig }
```
온체인 기록 없음. 담보 0. 되묻기는 **담보를 걸기 전**에만 의미가 있다 — 이미 낸 주장은 되묻기로 구제되지 않는다(R4).

**R2 응답 레코드 `reading-selection/v0.1`.** `{ responder, clarification_id, choice ∈ {1..m} ∪ {none}, sig }`. **자유 텍스트 금지 — 응답 공간은 인덱스뿐.** 담보 없음, **응답 보상 R_q = 0**(§3.5 T-D). 응답 의무 없음(α < 1 허용), 시한 없음(발화자 자기 마감만). 응답자는 서명으로 해석에 **구속**된다(담보가 아니라 서명으로): 이후 "다른 뜻이었다"는 이의는 판정에 무효(R3).

**R3 새 발화 개설.** 응답 후 발화자는 **새** `assertion/v0.1` 을 낸다 — `bound` 에 `pinned_reading = r_choice`, `context` 에 되묻기 스레드 해시. **새 id·새 담보·새 t_claim**(Exp30 R1). 판정기는 오직 pinned reading 아래에서 판정한다(Exp25 z3-2 패턴: I 를 싱글턴으로 못박음). 같은 질의에 이미 계류 주장 h 가 있었어도 h 는 **무영향** — 철회·보류·연장 없음.

**R4 정산 무접촉 (핵심 조건).** 주장 상태기계(Exp30 §4: `None →engage→ Engaged →verdict→ Settled`, `None →lapse→ Settled`)에 ASK 전이는 **존재하지 않는다**. ∀h: T_settle(h) 는 ASK 열의 함수가 아니다. A2A `INPUT_REQUIRED`(같은 taskId 중단)와 정반대. T_max = 180,000s(Exp30 R11)는 그대로다.

**R5 비용 부담.** 발화자 c(가스·지연·기회비용 — 담보 아님). 응답자 c_r(주의, 자발적, α 로만 표현). 프로토콜 0. 보상 0(질문·응답 모두). **기권 수수료 없음** — 작업서 ⑦: 수수료 c' 는 τ\* 를 (B−c')/(B+R) 로 낮춰 기권을 *줄이는* 쪽으로 밀어 목적과 반대.

**R6 횟수 상한·정련.** 같은 `context_hash` 에 k_max = **3**(사전등록). 라운드 k+1 의 I 는 라운드 k 응답과 정합하는 해석만(엄격 정련). 상한 후 행위는 {ANSWER, ABSTAIN} 만. 시빌로 context 를 바꾸면 상한을 우회한다 — 그래도 얻는 건 없다(R5: 프로토콜 지급 0) → **가격표이지 방지 아님**(백서 §9.4).

**R7 유도·낚시 봉쇄.** `readings` 는 **질문의 해석**(슬롯)이지 답이 아니다. 토이에서 답은 규칙 폐포(검증기)가 계산하므로 응답이 답을 실어 나를 수 없다. `none_option` 필수 — 유도 질문(anchoring)의 최소 방어.

**R8 기존 abstain 경로 무변경.** 판정자가 정산 시 'abstain' 태그를 찍는 v0.2/v0.3 경로는 그대로다. ASK 후 ABSTAIN 으로 끝나면 온체인엔 아무것도 없다(애초 담보를 안 걸었다).

**R9 온체인 변경 0.** BondedValidatorV3·PanelV3·렌즈 무수정. 슬래싱 규칙 무변경 → 마스터플랜 불변원칙상 A2A 심의·오너 결재 항목 없음(문서 §10).

## 3. 수학

### 3.1 불확실성 좌표 (스칼라 p 를 두 축으로)

추출기(Exp1)는 문장마다 세 헤드 (from, to, neg) 의 소프트맥스를 낸다.
- **능력 κ (최약고리, Exp2 신호 그대로):** 규칙 문장 전부·헤드 전부의 top-1 확률 최솟값. "규칙을 제대로 읽었나".
- **의도 확정도 w̃ (신규):** 질의 문장 헤드의 top-1 확률 곱, w̃ = Π_h q^h_(1). "질문을 한 가지로 읽었나". 해석집합 I 는 상위 m 개 슬롯 조합, ν = 1 − Σ_{r∈I} P(r) 이 "해당 없음" 질량.
- **직답 정답확률(보정 가정, 하한):** p̃ = w̃·κ. 실제 P(정답) = w̃κ + (1−w̃)·P(다른 해석에서도 같은 답) ≥ w̃κ — 우연 일치 항은 버린다(보수적).
- 엔트로피 H(q)/log n 은 **보조 지표**로만 보고한다. 결정에 쓰는 양은 "argmax 해석이 의도일 확률" w̃ 이지 분포의 퍼짐이 아니다(둘은 3-way 50/25/25 와 2-way 50/50 을 다르게 본다).

Gemini 원안의 "엔트로피 초과 시 온체인 반려"는 두 가지로 불가하다: 체인은 로짓을 못 본다(Exp28 B3); 반려는 기권 수수료와 같은 급의 역효과(R5). 본 설계에서 확신도는 **발화자의 오프체인 결정 변수**이고, 온체인엔 결정의 결과(새 주장)만 도달한다. 공개는 §3.6 의 선택 사항이다.

### 3.2 가치와 임계 (Chow 1970 의 재표기)

V0(q) = max(0, q(B+R) − B) — 확신 q 로 "답하거나 기권" 할 때의 최선 기대이익. 답 ≻ 기권 ⟺ q ≥ τ\* = B/(B+R). (Chow: 정답 0·오답 B+R·기권 R 의 비용 ⇒ 임계 1 − R/(B+R). 동치.)

### 3.3 되묻기의 가치 (근시안 1라운드)

응답이 오면(α) 해석이 못박혀 p̃ → κ 가 되고, "해당 없음"(ν)이면 이번 라운드는 0(근시안), 응답이 없으면(1−α) 현 p̃ 로 Chow.

V_ask = −c + α[(1−ν)·V0(κ) + ν·0] + (1−α)·V0(p̃)

**결정 규칙(3분할):**

ASK ⟺ α(1−ν)·[V0(κ) − V0(p̃)] > c  … (EVPI > 비용; SAGE-Agent 규칙의 담보판)
그 외 ANSWER ⟺ p̃ ≥ τ\*, 그 외 ABSTAIN.

닫힌형(V0 가 선형인 영역):
- p̃ ≥ τ\* 인 곳: ASK ⟺ **(1 − w̃) > ε_q := c / (α(1−ν)·κ·(B+R))** — "모호 질량이 문턱을 넘으면 답할 수 있어도 먼저 묻는다".
- p̃ < τ\* 인 곳: ASK ⟺ **κ > τ_κ := τ\* + c / (α(1−ν)(B+R))** — "해석만 확정되면 답할 수 있을 만큼 능력이 있을 때만 묻는다"; κ ≤ τ_κ 면 묻지 않고 기권("모르는 건 물어도 모른다").

이것이 오너 통찰의 수학적 형태다: 자연어 중간 구간의 오류는 (1−w̃) 질량이고, 되묻기는 그 질량을 담보 발화가 아니라 **질문으로 라우팅**한다. 환각은 제거되지 않는다 — 좌표가 바뀌어 가격이 붙는다.

### 3.4 다라운드

k ≤ k_max. 라운드마다 위 규칙을 근시안 적용(V_next = 0). 유한지평 DP 는 풀지 않는다(한계 §8-8). 예상: 정련 후 w̃ → 1 이라 2라운드 이상은 드물게 발화(측정 항목).

**Exp18 τ\* 와의 관계(한 문장):** 되묻기 옵션은 답/기권 경계 τ\* 를 **움직이지 않는다**(T-A). 바꾸는 것은 정책의 차원이다 — 스칼라 θ 하나가 (θ_ans → τ\*, θ_ask → ε_q) 둘이 되고, 직답률은 ASK 질량만큼 줄되 **최종 커버리지·담보점수는 Σ_ASK [α(1−ν)(V0(κ)−V0(p̃)) − c] 만큼 오른다**(양수는 규칙이 보장).

### 3.6 확장 — 정당한 되묻기의 공개 검증 (Exp16 연결, 조건부)

Exp16 공개 인스턴스는 입력 해시 1 + 로짓 62(= from 30 + to 30 + neg 2 — `models.py` 헤드 구성과 일치, 회로 정의 재확인 필요). **질의 문장 1개**의 로짓이 공개되면 검증자는 w̃ 를 재계산해 "(1−w̃) > ε_q 였다"를 확인할 수 있다 — Confidential Guardian(Mirage: 고의 저확신으로 서비스 거부) 방어의 경제층 결합. κ 는 규칙 문장 전부의 로짓이 필요해 **현 회로(문장 1개/증명)로는 불가** — 집계·배치 증명(P10)까지 한계. 되묻기 자체는 온체인에 없으므로 이 증명은 **새 주장의 proofHash 에 실린 부속물**이고, 기능은 "이 발화자가 묻고 나서 답했다"의 검증 가능 이력(렌즈·상대의 α 결정 재료)이다.

## 8. 정직하게 못 하는 것 (전량 등재)

1. **환각을 제거하지 않는다.** 의도 모호성 질량 (1−w̃) 을 질문으로 라우팅할 뿐이고, 지식 결손(MISS-RULE)은 여전히 기권으로만 처리된다. 제목이 "수학으로 환각 제거"가 아닌 이유.
2. **개념적 신규성 없음.** 임계 = Chow 1970, 담보+무손실 기권 = WALLA, 질문 = 기권 = Singh/FIPA·AgentAbstain, 게이트 = SAGE EVPI, 정당성 증명 = Confidential Guardian. 우리 것은 세 조건의 교집합(§1)뿐 — 그랜트·백서에서 이 이상 쓰지 말 것.
3. **토이.** Exp1 합성 문법(어휘 58)·템플릿 모호성·오라클 상대·사람 0. "자연어 중간 구간이 환각 원천"이라는 오너 통찰은 합성 모호성에서만 시험된다. 실세계 외삽 근거 아님.
4. **보정 가정 상속(Exp2·18).** p̃ = w̃κ 가 정답확률이라는 가정은 K1(d)로 측정하지 증명하지 않는다. 우연 일치 항은 버렸다(하한).
5. **되묻기 경제는 외부효과.** 상대의 주의 비용은 α 하나로만 들어오고 α 는 외생이다. 평판 기반 α 내생화·사람 시간 가격은 모델 밖.
6. **'해석 ≠ 답' 경계는 도메인 의존.** 토이에서는 해석 = 슬롯·답 = 폐포라 답 낚시가 형식적으로 막히지만, 일반 도메인에서 그 경계는 보장되지 않는다(자유 텍스트 도메인은 범위 밖).
7. **유도 질문은 인간요인.** none 옵션은 최소 방어이고, 제시된 선택지에 끌리는 편향은 기계로 못 막는다.
8. **다라운드 최적화 미해결.** 근시안 규칙 + k_max = 3. 유한지평 DP 와의 차이는 측정만 한다.
9. **zk 확장은 w̃ 만.** κ(전 문장 최약고리)는 현 회로(문장 1개/증명)로 검증 불가 — 집계·배치 증명(P10)까지 한계. 62 로짓 구성(from 30·to 30·neg 2)은 헤드 구성에서 추정, 회로 정의로 재확인 필요.
10. **온체인 0 = 억지력 주장 0.** 본 실험은 시뮬·규격 수준이며, "지연 공격 폐쇄"는 구조적 사실(전이 없음)이지 배포 실측이 아니다.
11. **비발화 지연은 자유.** R4 의 대가: 상대가 마감 안에 답을 기대하는 시장에서 "묻고 안 답함"은 비발화 = 기권이며, 소비자가 그렇게 취급해야 한다(UX 비용).
12. **갭 실측 미재확인.** §1 은 별도 렌즈의 2026-09-03 웹 실측 인용이며 본 렌즈는 URL 을 다시 열지 않았다. FIPA query-if 원문은 그 렌즈도 미확인이라 밝혔다.
13. **합성 검산 표(§9)는 실데이터가 아니다.** Chow 오답률 17% 는 검산용 분포가 Exp2 실측(0.66%)보다 훨씬 가혹하게 설정됐기 때문이며, K2 의 실제 마진은 훨씬 작을 수 있다 — K2 임계(×1.05)는 그래서 상대값이다.
14. **Arm A 가 실패할 가능성이 높다.** 생략·대명사 토큰은 학습 어휘 밖이라 κ 축(미지 토큰)으로 새어 기권이 나올 수 있다 — 그 경우 "분해는 공짜가 아니다"가 정직한 결과이고 Arm B 로 넘어간다.
